Database Schema & Migration

Adding User association to AnalysisSession table

A

Strict Non-Nullable UserId (Recommended)

Every analysis session must belong to a user (Guid UserId). High integrity schema. Existing records in the DB will be migrated to a default seed user during the migration execution.

B

Nullable UserId for Compatibility

Allows sessions without an owner (Guid? UserId). Existing records remain orphaned and can either be viewed by everyone or hidden. New sessions created via the UI will associate with the logged-in user.
