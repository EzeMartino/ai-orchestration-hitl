Identity & JWT Database Architecture

Selected: Microsoft Identity + JWT Token Authentication

A

Integrated DbContext (Recommended)

Inherit OrchestrationDbContext from IdentityDbContext. All tables (Users, Roles, AnalysisSessions, ActivityEvents) reside in the same PostgreSQL database. Simple transactions, unified migrations, easy querying.

B

Separate DbContext / Database

Create a separate AppIdentityDbContext for identity tables, potentially in a separate database. Keeps the analysis domain isolated from user management, but requires cross-context queries/coordination.
