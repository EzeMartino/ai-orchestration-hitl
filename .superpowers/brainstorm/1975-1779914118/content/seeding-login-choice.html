User Seeding & Frontend Entry Flow

Designing the authentication entry point and development developer experience

A

Automatic Seeding (Recommended)

Seed a default administrator (e.g., admin@ezemartino.com) with a default secure password on backend startup. Existing analysis sessions are migrated to this user. Allows instant login and out-of-the-box demoing.

B

Manual Registration Only

Start with a completely empty database. Existing sessions are assigned to a new user created during development. No hardcoded default users are seeded in the database initialization.
