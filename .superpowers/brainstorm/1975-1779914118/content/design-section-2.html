Section 2: API Authentication & Identity Endpoints

Mapping built-in Microsoft Identity APIs & JWT Token configuration

Backend Service Pipeline (Program.cs)
// 1. Add Identity & Database Services
builder.Services.AddIdentityApiEndpoints<IdentityUser<Guid>>()
    .AddEntityFrameworkStores<OrchestrationDbContext>();

// 2. Configure JWT options in appsettings.json
"Authentication": {
  "Schemes": {
    "Bearer": {
      "ValidAudience": "http://localhost:5148",
      "ValidIssuer": "http://localhost:5148",
      "SigningKeys": [ { "Issuer": "http://localhost:5148", "Value": "YOUR_SUPER_SECRET_KEY..." } ]
    }
  }
}

// 3. Map Endpoints in Middleware Pipeline
app.UseAuthentication();
app.UseAuthorization();

app.MapGroup("/api/auth").MapIdentityApi<IdentityUser<Guid>>();
Automatic Admin Seeding Service
IdentityDataSeeder (IHostedService): Runs automatically at application startup. Checks if the database contains the admin user (admin@ezemartino.com). If not:
1. Creates the user with the specified GUID so that legacy analysis records are successfully resolved.
2. Hashes and sets the default password (e.g. AdminPass123!).
3. (Optional) Adds the user to the "Administrator" role.
